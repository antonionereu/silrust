SILRUST v1.2 — ATUALIZAÇÃO DO GITHUB
====================================

O ChatGPT consegue ler o repositório antonionereu/silrust, mas a integração
GitHub continua a devolver HTTP 403 quando tenta escrever ficheiros.

Para aplicar esta atualização ao repositório:

1. Extrair SilRust-v1.2-GitHub-update.zip.
2. Na raiz do repositório, carregar/substituir:
      silrust-v1.2-overlay.zip
      VERSION.txt
3. Dentro de .github/workflows/ substituir:
      build-silrust.yml

Assim que build-silrust.yml ou silrust-v1.2-overlay.zip for enviado,
o GitHub Actions arranca automaticamente.
